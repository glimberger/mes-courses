# Implementation Plan: Mockup-Faithful UI

**Branch**: `feat/008-mockup-fidelity-ui` | **Date**: 2026-10-17 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/008-mockup-fidelity-ui/spec.md`

## Summary

Make every screen and dialog match the approved HTML mockups in `design/mockups/`, which
feature 007 approached but did not reach. The gap analysis ([research.md](research.md#gap-analysis-why-feature-007-does-not-match))
traces the visible differences to a handful of token and shared-component causes: Nunito
mapped to the regular weight, Material Design Icons instead of Material Symbols Rounded,
tonal Android elevation instead of the soft two-layer shadows, a missing soft-yellow role, a
Paper checkbox, field radii Paper ignores, and Paper's fixed `Appbar` and default dialog and
snackbar looks.

The fix is presentational and stays in the mobile UI adapter and the design export:

- `design/material-theme.json`: dark card value on `surfaceContainerLowest`, new
  `brandSoft`/`onBrandSoft` pair, warm `scrim` and light `shadow` (all six schemes).
- Theme modules: a mockup type scale (`typography.ts`), extra radii (`shape.ts`), `boxShadow`
  tokens built from roles (`elevation.ts`).
- Icons: a bundled Material Symbols Rounded subset (weight 500, plus a weight 700 `check`),
  generated by a script and wired into Paper through `settings.icon`.
- Shared components: new `ScreenHeader`, `Card`, `Chip`, `BrandCheckbox`, `AppDialog`,
  `BrandSnackbar`, `EmptyCategoryCard`; existing rows, buttons, FAB, fields, states and settings blocks brought to
  the [building-block contract](contracts/ui-building-blocks.md).
- Screens: recomposed only where their structure differs from a mockup (headers, card
  grouping, dialog layouts, settings sections).

No flow, text, label, identifier, data or sync behavior changes.

## Technical Context

**Language/Version**: TypeScript 6.0 (strict); React 19.3; React Native 0.88.0-rc.3 (new
architecture only); Expo SDK 58

**Primary Dependencies**: React Native Paper 5.15 (Material 3, patched), `expo-font`,
`@expo/vector-icons` (`createIconSet`), `react-native-safe-area-context`; build-time only:
fonttools (`varLib.instancer`, `pyftsubset`) through `nix shell`, not a project dependency

**Storage**: N/A (no data, migration or protocol change)

**Testing**: Jest 30 + React Native Testing Library (component and screen tests on rendered
styles), theme tests (styles.css ↔ export equality, WCAG pairs, type scale), icon resolution
test, required-story test, Storybook stories, Detox story captures (`yarn screenshots:*`),
unchanged Detox device suites

**Target Platform**: Android and iOS (Expo builds, production and staging variants), light and
dark appearance, portrait, text size up to 200 %

**Project Type**: Offline-first mobile app (`apps/mobile`); server, delivery and
`packages/sync-core` untouched

**Performance Goals**: no startup regression: two more small font files in the existing
`useFonts` call (subset icon fonts of a few tens of kB); list scrolling stays smooth with
`boxShadow` on cards (one shadow per card, no nested shadows)

**Constraints**: presentational only (FR-012); Material 3 and the single color export
(Principle V, FR-003); 48 dp targets and no clipping at 200 % (FR-013); WCAG AA pairs in both
appearances (FR-014); bundled assets only (FR-015); strict TDD (Principle I)

**Scale/Scope**: 13 mockups (5 screens, dark current list, 4 dialogs, splash, 2 snackbars),
about 25 shared components, 10 screens and every dialog recomposed or restyled, 1 design export,
1 generation script, 2 font assets

No NEEDS CLARIFICATION remain; research resolved the open choices (R1–R10).

## Architecture Decisions

- **New**: ADR 0012 "Material Symbols Rounded as the icon set", created in the implementing
  pull request: bundled static subsets generated from the pinned variable font by
  `design/icons/build-symbols.sh`, rendered through `createIconSet` and Paper's
  `settings.icon`. It outlives this feature: every later screen uses this icon set and this
  generation step (research R5).
- **Relies on**: [ADR 0001](../../docs/adr/0001-react-native-expo.md) (Expo stack),
  [ADR 0003](../../docs/adr/0003-storybook-on-device.md) (on-device stories and captures),
  [ADR 0004](../../docs/adr/0004-detox-end-to-end-tests.md) (Detox, used for the story
  captures).
- Theme values, type scale, radii and shadows are design tokens: they stay in research.md and
  data-model.md, not in an ADR.
